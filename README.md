# CampusFind

CampusFind is a browser-based Campus Lost & Found system designed to help students report and search for lost or found items.

## Features

- Report lost or found items
- Add item name, location and description
- Upload item images
- Search reports
- Filter Lost and Found items
- Dashboard with report statistics
- Mark items as Claimed
- Contact Owner option
- Browser-based data persistence

## Tech Stack

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start reporting and browsing items.

## Project Status

This is a working frontend MVP. Future improvements may include a backend, shared database and multi-user functionality.
